# Definition of Done

Una historia no está terminada si falta cualquiera de:

- especificación/ADR relevante;
- migración DB;
- RLS;
- permisos;
- validación servidor;
- pruebas unitarias;
- pruebas de integración;
- prueba E2E si afecta flujo crítico;
- auditoría si es acción crítica;
- idempotencia si crea impacto financiero/fiscal;
- métricas/logs;
- documentación API;
- caso de reversión/rollback;
- compatibilidad móvil/web;
- revisión contable para posting;
- revisión fiscal si altera documento/impuesto;
- revisión de homologación si cambia comportamiento fiscal.
