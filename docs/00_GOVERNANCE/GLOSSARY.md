# Glosario

- **AR / CxC:** cuentas por cobrar.
- **AP / CxP:** cuentas por pagar.
- **Fiscal ledger:** registro inmutable de documentos/eventos fiscales.
- **Posting:** acto que vuelve definitivo un asiento contable.
- **Reversal:** asiento opuesto que neutraliza otro sin modificarlo.
- **Imprenta digital:** proveedor autorizado que participa en asignación/validación de documentos digitales según PA102.
- **PA102:** SNAT/2024/000102.
- **PA121:** SNAT/2024/000121.
- **RLS:** Row Level Security.
- **Tenant:** cliente SaaS.
- **Empresa:** entidad legal/RIF administrada dentro de un tenant.
- **Serie:** prefijo/identificador de secuencia documental.
- **Outbox:** patrón transaccional para publicar eventos sin perder consistencia.
- **VEN-NIF:** marco contable venezolano aplicable según clasificación de entidad; validar con profesional.
