# UX benchmarks

## Adoptar
- Dashboard entendible sin jerga contable para administradores.
- Acciones rápidas de Fina.
- Flujo de compra orden→recepción→factura visto en Valery.
- POS táctil rápido.
- Selector de empresa/sucursal persistente.
- Reportes descargables.

## Mejorar
- Cada pantalla debe explicar impacto: inventario, CxC/CxP, contabilidad, fiscal.
- Preview antes de posting/emisión.
- Timeline del documento.
- Diferenciar “borrador” vs “emitido”.
- Errores con solución concreta.
- Mobile con tareas de campo, no copiar todas las tablas desktop.

## Evitar
- Formularios gigantes.
- Menús anidados de 4+ niveles.
- edición destructiva de registros fiscales.
- campos técnicos sin ayuda.
- esconder tasa usada en conversiones.
