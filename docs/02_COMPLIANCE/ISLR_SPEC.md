# ISLR

## Alcance
Ladino debe soportar:
- conceptos de retención configurables;
- porcentajes/sustraendos/unidades cuando la norma aplicable lo establezca;
- retenciones a proveedores;
- comprobantes;
- acumulados;
- exportaciones.

## Regla crítica
No hard-codear tablas ni porcentajes. Modelar parámetros efectivos por fecha y tipo de sujeto/concepto.

## Control
Cada cálculo muestra:
- concepto;
- base;
- fórmula;
- parámetros;
- fuente;
- versión.
