# Claude / IA

## Casos permitidos
- explicar reportes;
- resumir cartera;
- sugerir categorización;
- OCR/extraer propuesta de factura de compra;
- detectar anomalías;
- redactar mensajes de cobro;
- búsqueda semántica;
- ayudar a construir filtros/reportes.

## Casos no autoritativos
Claude no puede:
- asignar número fiscal;
- decidir tasa legal definitiva;
- postear asiento sin reglas/aprobación;
- cerrar periodo;
- aprobar pago;
- modificar documento emitido.

## Tool use
Claude invoca herramientas con permisos del usuario; herramientas de escritura exigen validación servidor.

## Evidencia
Guardar:
- modelo;
- tool calls;
- usuario;
- resultado;
- aprobación humana para acciones críticas.

## Privacidad
Redactar datos innecesarios y configurar retención/proveedor conforme contratos.
