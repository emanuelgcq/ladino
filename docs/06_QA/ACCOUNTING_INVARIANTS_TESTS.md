# Tests de invariantes contables

1. Cada asiento posted balancea exactamente.
2. Posted no admite update/delete.
3. Reversal suma cero con original.
4. Evento fuente no genera dos asientos.
5. Periodo cerrado rechaza posting.
6. Subledger AR = control account bajo reglas.
7. Subledger AP = control account.
8. Inventario valorizado = cuentas de inventario bajo alcance configurado.
9. Diferencial cambiario reproduce tasa congelada.
10. Redondeos no crean asientos desbalanceados.
11. Import masivo conserva invariantes.
12. Concurrencia no duplica posting.
