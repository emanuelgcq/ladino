# Escenarios E2E fiscales

1. Venta contado gravada → factura → control → asiento → caja → libro.
2. Venta crédito → CxC → cobro parcial → cobro total.
3. Devolución parcial → NC → inventario → AR.
4. Ajuste posterior → ND.
5. Factura exenta/mixta.
6. Cliente persona natural sin RIF bajo supuesto permitido.
7. Reintento tras timeout imprenta.
8. Concurrencia de emisión.
9. Contingencia internet.
10. Auditor SENIAT consulta factura/eventos.
11. Intento de alterar factura.
12. Cambio de versión fiscal no autorizada bloqueado.
