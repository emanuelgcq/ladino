# Guía de migración desde sistemas legados

## Estrategia
1. inventario de fuente.
2. corte.
3. export.
4. limpieza sin alterar evidencia.
5. mapeo.
6. dry-run.
7. reconciliación.
8. aprobación contador.
9. carga producción.
10. freeze de fuente.

## Evidencia
Guardar archivos fuente, hash, mapping version, errores y reporte de conciliación.
