# Reglas UX móvil

- acciones de campo primero;
- formularios en pasos;
- escáner de barcode/cámara;
- targets táctiles grandes;
- estado de sincronización visible;
- no ocultar si operación es borrador vs definitiva;
- confirmación reforzada al emitir/pagar/postear;
- nunca mostrar “éxito” antes del commit server.
