# Flujos UX

## Venta
Cliente → carrito/pedido → validación stock/precio/impuesto → cobro/crédito → preview fiscal → emitir → comprobante → asiento.

## Compra
Proveedor → OC → recepción parcial → factura → match → retención → CxP → pago.

## Cierre caja
Abrir → operar → contar → diferencias → aprobación → cerrar.

## Cierre contable
Checklist → conciliaciones → subledgers → ajustes → preview → cerrar.

## Documento
Header + estado + timeline + tabs: detalle / pagos / inventario / contabilidad / fiscal / auditoría.
